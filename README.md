# NJU 补选助手（收藏课程）

这是一个用于南京大学本科选课平台的 Tampermonkey 单文件脚本。它在已登录的选课页面中工作，读取当前轮次的收藏课程，并在平台明确显示有空位时提交选课。

脚本不保存学号、密码、Cookie 或 token，只使用当前页面已有的登录状态和平台自身的选课接口。

## 能做什么

- 读取当前轮次的全部收藏课程，并默认全部勾选。
- 只对已勾选、尚未选中且明确有空位的课程提交选课。
- 多门课程逐门运行；抢到一门后只停止该课程，其他课程继续等待。
- 日志最新内容显示在最上方，抢课成功日志使用强调色。
- 状态栏显示运行状态、上次检查时间、下次检查倒计时和本次成功数量。
- 面板可以拖动、折叠和关闭。
- 运行过程中可以清空并重新输入检查间隔，新数值从下一次计时开始生效。

脚本只会发起选课操作，不包含退课、换课或取消收藏功能。

## 安装

1. 在浏览器中安装 Tampermonkey。
2. 打开 `nju-course-grabber.user.js`，复制全部内容。
3. 在 Tampermonkey 中新建脚本，替换编辑器里的默认内容并保存。
4. 登录 <https://xk.nju.edu.cn/>，选择正确的选课轮次并进入课程列表。
5. 先在选课平台中收藏目标教学班。
6. 点击面板中的“读取收藏”，取消不需要的课程，再点击“开始”。

## 运行规则

- 默认间隔为 2000 毫秒，最低为 1500 毫秒，每次还会增加 0–500 毫秒随机等待。
- 输入框清空时暂按默认间隔运行；输入新数字后，下一次计时会使用新数值，已经开始的当前倒计时不会中途重置。
- 平台只有明确返回成功码时才会计为抢课成功，不根据提示文字猜测。
- “当前时段不允许选课”等暂时性失败不会永久停掉课程，后续仍会继续检查。
- 收藏或余量读取超时后会自动恢复并重试。
- 提交请求或提交后的结果查询超时时，脚本会停止并锁定“开始”按钮。此时必须刷新页面、确认实际选课结果后才能继续，防止重复提交。
- 课程冲突、超过上限、无资格或重复修读等明确的永久失败，只会停止对应课程，不影响其他课程。

## 注意事项

- 必须保持电脑开机、浏览器页面打开且登录状态有效；电脑休眠、页面关闭或登录过期后无法继续运行。
- 平台页面或接口发生变化时，脚本可能需要更新。
- 首次使用建议只选择一门课程并观察日志。

## 本地语法检查

```sh
node --check nju-course-grabber.user.js
```
